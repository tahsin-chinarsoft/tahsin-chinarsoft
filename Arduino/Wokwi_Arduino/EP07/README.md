# Episode 7: PWM: Fade an LED and Mix Any Color

▶ Video: https://youtu.be/Olixj_Vkewk

| Folder | What it shows | Run in Wokwi |
| --- | --- | --- |
| `fade/` | Real fade on PWM pin 9 | https://wokwi.com/projects/480365213467459585 |
| `rgb_mixer/` | RGB color mixer with 3 pots | https://wokwi.com/projects/480365451194445825 |
| `wrong_pin/` | analogWrite on pin 12: on/off only | https://wokwi.com/projects/480365057313424385 |
| `homework_solution/` | Homework solution: Red to blue fade with millis() | https://wokwi.com/projects/480369004397748225 |

Each folder has `sketch.ino` and `diagram.json` (and `libraries.txt` if libraries are needed). Open the Wokwi link to run it in your browser, no hardware needed.
