# Arduino in Your Browser (Wokwi, No Hardware)

A free 20-episode Arduino Uno course on the ChinarSoft YouTube channel. Every project runs in your browser in [Wokwi](https://wokwi.com), so you do not need to buy any hardware.

▶ Start with Episode 1: https://youtu.be/RtahydF3pzs (the whole series is in the "Arduino in Your Browser (Wokwi, No Hardware)" playlist on the ChinarSoft channel)
